# Samrudhi Vitthal Kharoshe - Portfolio

## Files
- `index.html` — website structure/content
- `style.css` — responsive design and animations
- `script.js` — theme switcher, typing effect, mobile menu, project filter and form interaction

## Run
Open `index.html` in Chrome/Edge/Firefox.

No backend or Gradle setup is required.

## Customize
1. Replace `your-email@example.com`.
2. Replace `#` links with your real GitHub and LinkedIn URLs.
3. Update project descriptions and links.
4. Add a real profile photo if desired.
5. Change colors in `:root` inside `style.css`.
