# Samrudhi Vitthal Kharoshe — Portfolio

A responsive personal portfolio built with HTML, CSS and vanilla JavaScript.

## Features

- Mobile-friendly responsive layout
- Dark/light theme switcher
- Typing effect in the hero
- Animated project filter (All / Web / Python / Java)
- Contact form UI

## Files

| File          | Purpose                                        |
| ------------- | ---------------------------------------------- |
| `index.html`  | Website structure and content                  |
| `style.css`   | Responsive design and animations               |
| `script.js`   | Theme, typing effect, menu, filter, form logic |

## Run

Open `index.html` in any modern browser (Chrome, Edge, Firefox).

No build step or backend required.

## Live Site

GitHub Pages: (enable it in Settings → Pages if you want to host this repo)

## Customize

1. Replace the project `#` links with your real project/GitHub URLs.
2. Connect the contact form to a service like Formspree or EmailJS.
3. Add a profile photo if desired.
4. Change the color theme in `:root` inside `style.css`.
